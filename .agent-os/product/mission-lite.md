# Product Mission (Lite)

IFLA Standards Platform is a comprehensive library standards documentation and management system that helps library professionals, standards editors, vocabulary managers, and content authors collaborate on international library standards by providing multi-site documentation, administrative workflows, and RDF-based vocabulary management.

The platform serves the global library community with dedicated Docusaurus sites for each IFLA standard (FRBR, LRM, ISBD, ISBDM, MULDICAT, UNIMARC) and an integrated Next.js admin portal for vocabulary management. Unlike traditional documentation platforms, it combines Git-based version control with sophisticated development workflows, shared component architecture, and automated publication pipelines.

**Current Status:** Multi-site documentation and development infrastructure complete. Admin feature implementation in progress with focus on replacing mock data with functional interfaces and completing API contracts.
