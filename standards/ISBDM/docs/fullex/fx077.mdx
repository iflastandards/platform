# Corso delli Fiumi Drino e Boiana nella Dalmatia (2007; Bibliothèque nationale de
              France; online resource; PDF)

This example describes an online resource that embodies a digitized reproduction of
              an older printed map.

The original item is held by the National Library of France; the reproduction
              manifestation is in the digital library of the National Library of France.

The manifestation is published in a single unit.

The manifestation is not an aggregate.

The manifestation embodies a static work.

The language of cataloguing is English.

The description is intended for a relational database application.
