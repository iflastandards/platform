<Example
  header="Using Components in Values"

    {

    }
  ]}
  note="This example shows how to use Mandatory, Unique, and InLink components within property values."
/>

## Summary

These components provide:

1. **Consistent Formatting** - All examples look the same across documentation
2. **Accessibility** - Full keyboard and screen reader support
3. **Global Availability** - No imports needed in MDX files
4. **Flexibility** - Support both structured data and custom content
5. **Integration** - Work seamlessly with existing IFLA theme components

The components are now ready for use across all IFLA documentation sites!
