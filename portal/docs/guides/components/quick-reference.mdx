# Examples Components Quick Reference

Quick reference guide for the new Examples, Example, and Steps components. All components are globally available - no imports needed!

## Examples Component

Collapsible container for example content.

### Basic Usage
```mdx
<Examples>
  <p>Your content here</p>
</Examples>
```

### With Custom Summary
```mdx
<Examples summary="Property Examples" open>
  <p>Content here</p>
</Examples>
```

### Props
- `summary?: string` - Summary text (default: "Examples")
- `open?: boolean` - Initially expanded (default: false)
- `children: ReactNode` - Content

---

## Example Component

Structured example with property-value tables.

### Structured Properties
```mdx
<Example
  properties={[
    { property: "name", value: "value" },
    { property: "type", value: "manifestation" }
  ]}
  fullExampleHref="/docs/examples/sample"
/>
```

### Custom Content
```mdx
<Example header="My Example">
  | Property | Value |
  |----------|-------|
  | Type     | Book  |
</Example>
```

### Props
- `header?: ReactNode` - Example header
- `label?: ReactNode` - Example label
- `properties?: ExampleProperty[]` - Structured data
- `fullExampleHref?: string` - Link to full example
- `note?: ReactNode` - Footer note
- `showTableHeader?: boolean` - Show Property/Value headers (default: true)
- `children?: ReactNode` - Custom content

## Steps Component

Configurable nested list numbering.

### Basic Steps
```mdx
<Steps>
  <ol>
    <li>First step</li>
    <li>Second step</li>
  </ol>
</Steps>
```

### Custom Numbering
```mdx
<Steps level1="upper-alpha" level2="decimal" level3="lower-roman">
  <ol>
    <li>Step A
      <ol>
        <li>Sub-step 1
          <ol>
            <li>Detail i</li>
          </ol>
        </li>
      </ol>
    </li>
  </ol>
</Steps>
```

### Props
- `level1?: string` - First level style (default: "decimal")
- `level2?: string` - Second level style (default: "lower-alpha")  
- `level3?: string` - Third level style (default: "lower-roman")
- `children: ReactNode` - List content

### Available Styles
- `"decimal"` - 1, 2, 3...
- `"lower-alpha"` - a, b, c...
- `"upper-alpha"` - A, B, C...
- `"lower-roman"` - i, ii, iii...
- `"upper-roman"` - I, II, III...

## Common Patterns

### Assessment Documentation
```mdx
<Examples summary="Assessment Examples">
  <Example
    header="Single Unit"
    properties={[
      { property: "has unitary structure", value: '"single unit"' },
      { property: "decision", value: '"One manifestation"' }
    ]}
  />
</Examples>
```

### Process Documentation
```mdx
<Steps>
  <ol>
    <li>Assessment
      <ol>
        <li>Count units</li>
        <li>Identify content</li>
      </ol>
    </li>
    <li>Description
      <ol>
        <li><Mandatory />Record carrier</li>
        <li>Add details</li>
      </ol>
    </li>
  </ol>
</Steps>
```

### Integration with Other Components
```mdx
<Example
  properties={[
    { property: "title", value: <><InLink href="/docs/title">Main Title</InLink></> },
    { property: "mandatory", value: <><Mandatory />Required field</> }
  ]}
/>
```
